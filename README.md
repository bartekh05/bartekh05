### 🧩 The short version

I build interfaces in **React** and **Next.js**, and I follow them all the way down - API routes, **Prisma** schemas, **Postgres** queries - because "it's a backend problem" is rarely the whole story.

**TypeScript** everywhere. If a bug can be caught by the compiler instead of by a user, that's where I want it caught.

### 🔒 Mostly private

Everything I've shipped so far lives in private repos - client work and products, not libraries. So the graph below is the honest version of what I do: quiet, steady, and behind closed doors.
